# Сообщения об уязвимостях

Не размещайте токены, пароли, ключи, базы данных и резервные копии в публичных Issues или Pull Requests.

Для приватного сообщения используйте [Report a vulnerability](https://github.com/tro9n4ik/md-next/security/advisories/new). Не публикуйте детали уязвимости или секреты в обычных Issues. Если приватная форма недоступна, создайте Issue с просьбой предоставить приватный канал связи, без технических деталей.

В приватном отчёте укажите версию проекта, затронутый компонент и шаги воспроизведения на собственном сервере. Замените реальные адреса, аккаунты и ключи на примеры.

Обновление приложения не заменяет обновления ОС, ограничения доступа, проверку TLS и резервное копирование.

## Границы доверия к самообновлению

Обновление разрешено только для текущего main с подтверждённой подписью GitHub и успешными последними проверками CI и секретов. Verified подтверждает подпись, а не безопасность кода. Злоумышленник с доступом к аккаунту может добавить свой ключ и подписать вредоносные изменения. Защитите аккаунт двухфакторной аутентификацией, желательно аппаратным ключом; сохраняйте защиту main, обязательные проверки и запрет force-push. В проекте с одним разработчиком обязательное чужое ревью отключено: независимого одобрения при выпуске нет.

Workflows находятся в том же репозитории, что и устанавливаемый код. Проверки не являются независимым источником доверия: компрометация репозитория позволяет менять их вместе с приложением.

В процессе самообновления root выполняет pip install и npm ci из проверенного репозитория. Скрипты сборки и установки зависимостей получают эти права; подпись и CI не превращают сторонние пакеты в доверенные. Привилегированный установщик и помощник остаются частью доверенной базы, хотя сам backend работает от md-next.

Удаление или отключение VLESS-профиля, истечение срока и достижение лимита исключают пользователя из конфигурации и требуют перезапуска Xray при применении изменения. Это закрывает его текущие соединения и кратковременно прерывает соединения остальных Xray-клиентов. Добавление VLESS-пользователей выполняется через API без перезапуска. Контроль срока и трафика зависит от очередного цикла сбора статистики; мгновенное отключение ровно на границе лимита не гарантируется.

Копии помощника в /usr/local/lib/md-next пересоздаются при установке, активации самообновления и откате. Установщик сверяет содержимое, владельца root и запрет записи другими пользователями. Проверка установки также запускает этот контроль.

Новые ноды получают случайный shortId Reality на ноду. Старые ноды сохраняют прежний shortId до согласованного изменения обеих сторон. Фиксированный SNI www.cloudflare.com не обеспечивает гарантированной доступности во всех сетях.

Для удаления используйте scripts/uninstall.sh из установленного релиза. Старые сторонние копии скрипта могут не учитывать разделение прав.
