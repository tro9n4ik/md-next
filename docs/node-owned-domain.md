# Собственный домен межсерверного канала

Новые ноды используют HTTPS-домен той панели, к которой подключаются. Адрес берётся из `PANEL_PUBLIC_URL`: домен конкретной установки не зашит в общий установщик.

Перед регистрацией установщик проверяет доверие к сертификату, соответствие имени домена, TLS 1.3 и HTTP/2 на порту 443. При ошибке установка останавливается. Перехода на Cloudflare или другой чужой сайт нет.

Панель сохраняет домен отдельно для каждой ноды и использует его при создании обычных маршрутов и проверках WARP. При настроенном `PANEL_PUBLIC_URL` регистрация с другим доменом отклоняется. HTTPS-домен панели должен быть доступен с серверов нод.

## Уже подключённые ноды

Обновление панели не переключает старые ноды автоматически: их текущий SNI сохраняется для совместимости. Чтобы перейти на собственный домен, сначала обновите панель, затем переустанавливайте ноды по одной через новые приглашения. После каждой установки проверяйте связь и выход в интернет, прежде чем переходить к следующей ноде.

Используйте существующую функцию переустановки ноды, чтобы сохранить её идентификатор и связанные маршруты. Ссылка приглашения содержит секрет, её нельзя публиковать.

## Изменение домена панели

Домен уже подключённой ноды не меняется от одного редактирования `PANEL_PUBLIC_URL`: сохранённая привязка должна соответствовать конфигурации на самой ноде. Для смены домена понадобится согласованная перенастройка или переустановка.

Собственный сертификат устраняет использование сертификата чужого сайта, но не гарантирует разрешение REALITY или VPN правилами хостинга. Ограничения нужно уточнять у провайдера.
