# Автоматическая очистка диска

MD-Next использует отдельный каталог `/var/cache/md-next` для загрузок pip/npm и временных файлов штатного обновления. Ежедневный таймер `md-next-cache-clean.timer` удаляет только обычные файлы в этом каталоге старше 7 дней. Первый запуск после включения может выполнить пропущенное задание; время запуска смещается случайно в пределах часа.

Обновление и переезд используют общую блокировку `/var/lib/md-next/maintenance.lock`. Если она занята, очистка пропускается до следующего дня. Очистка не следует по символическим ссылкам, не переходит на вложенные файловые системы и пропускает файлы с чужим владельцем или правом записи для группы/остальных.

База, `.env`, сертификаты, VPN-конфигурации, резервные копии, `venv-releases`, рабочий `node_modules`, общие `/tmp`, кэши root и других приложений не очищаются. Свежий кэш также сохраняется. Это профилактика накопления файлов сборки, а не гарантия свободного места на любом VPS.

Таймер устанавливается при новой установке или успешном обновлении на версию с этим механизмом. Старая установленная программа обновления может один раз использовать прежний общий кэш; он автоматически не удаляется. Каталоги, оставшиеся от обновлений до перехода на отдельный кэш, также требуют отдельной проверки.

## Просмотр и управление

```sh
systemctl list-timers md-next-cache-clean.timer
journalctl -u md-next-cache-clean.service --no-pager -n 20
sudo python3 /usr/local/lib/md-next/disk-maintenance.py --dry-run
```

Журнал каждого запуска содержит JSON: количество удалённых файлов, сумму их логических размеров в байтах и число пропущенных объектов. Фактическое освобождение диска может отличаться из-за выделения блоков и открытых файлов. `--dry-run` ничего в кэше не удаляет.

Отключение расписания:

```sh
sudo systemctl disable --now md-next-cache-clean.timer
```

Последующие обновления сохраняют состояние существующего таймера: отключённый или замаскированный таймер автоматически не включается снова.

## Системные журналы

Глобальный journal и кэш APT могут использовать другие приложения, поэтому MD-Next не чистит их автоматически. Лимиты journald задаются администратором VPS отдельно. Очистка кэшей не заменяет достаточный размер диска и RAM/swap для сборки интерфейса.
