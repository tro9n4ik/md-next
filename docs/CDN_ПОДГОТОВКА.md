# Подключение CDN

Во вкладке «Обход БС» доступны домен, тумблер добавления дополнительного профиля в подписки и кнопка «Проверить CDN».

Для включения необходим действующий XHTTP TLS во вкладке «Протоколы». CDN использует UUID этого профиля, его срок действия, лимит трафика, счётчики и выбранный общий выход. Основные профили сохраняются. Клиенту требуется обновить подписку и выбрать «Обход БС · CDN».

Защищённый API: GET/PUT /api/v1/cdn, POST /api/v1/cdn/check. При включении проверяются HTTPS GET / и GET без тела на отдельный путь XHTTP в режиме packet-up, с данными в заголовках. Ошибка проверки возвращает 409 и не изменяет сохранённые настройки. Выключение не требует доступности CDN. Если домен выключен, профиль не выдаётся.

Проверка ограничена публичным IPv4, фиксирует адрес подключения, не следует перенаправлениям и проверяет TLS. Она подтверждает только доступность HTTPS и передачу XHTTP GET, а не полноценную работу VPN и не доступность в белых списках оператора. Эти проверки выполняются отдельно с телефона.

CDN должен сохранять путь и query string, разрешать GET и сохранять заголовки X-Data-*, работать без кеширования и без ограничений, мешающих XHTTP. POST от клиента к CDN не требуется. Общий размер пакета ограничен 2048 байтами; uplinkChunkSize=1000 ограничивает размер отдельных заголовков. Обычный XHTTP TLS сохраняет прежний вход 8446, CDN использует отдельный локальный вход 8447 и путь <путь TLS>/cdn-get. HTTPS-origin должен иметь правильные Host и SNI.

Основа транспорта: [официальная документация XHTTP](https://xtls.github.io/en/config/transports/splithttp.html).
