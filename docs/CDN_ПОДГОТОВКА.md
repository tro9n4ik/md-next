# Подключение CDN

Во вкладке «Обход БС» доступны домен, тумблер добавления дополнительного профиля в подписки и кнопка «Проверить CDN».

Для включения необходим действующий XHTTP TLS во вкладке «Протоколы». CDN использует UUID этого профиля, его срок действия, лимит трафика, счётчики и выбранный общий выход. Основные профили сохраняются. Клиенту требуется обновить подписку и выбрать «Обход БС · CDN».

Защищённый API: GET/PUT /api/v1/cdn, POST /api/v1/cdn/check. При включении проверяются HTTPS GET / и POST на путь XHTTP в режиме packet-up. Ошибка проверки возвращает 409 и не изменяет сохранённые настройки. Выключение не требует доступности CDN. Если домен выключен, профиль не выдаётся.

Проверка ограничена публичным IPv4, фиксирует адрес подключения, не следует перенаправлениям и проверяет TLS. Она подтверждает только доступность HTTPS и передачу POST, а не полноценную работу VPN и не доступность в белых списках оператора. Эти проверки выполняются отдельно с телефона.

CDN должен сохранять путь и query string, разрешать GET и POST, работать без кеширования и без ограничений, мешающих XHTTP. Ответ POST 413 означает, что включение невозможно до исправления ограничений провайдера. HTTPS-origin должен иметь правильные Host и SNI.

Основа транспорта: [официальная документация XHTTP](https://xtls.github.io/en/config/transports/splithttp.html).
