Порядок: завершить проверки публикации, затем подписи обновлений и защищённый канал нод, после этого реальные сетевые проверки. Не включать перехват DNS или блокировку QUIC для всех пользователей без проверки влияния на соединения.

Двухфакторную аутентификацию аккаунта GitHub и аппаратный ключ настраивает владелец аккаунта. Защита ветки должна требовать ревью и запрещать force-push; порядок выпуска при этом нужно перевести на Pull Requests.
