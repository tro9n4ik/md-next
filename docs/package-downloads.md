# Резервный источник npm

Новая установка, обновление из консольного установщика и обновление через панель используют один помощник `scripts/npm-install.py`.

1. Сначала используется основной npm-репозиторий `https://registry.npmjs.org/`.
2. При сетевой ошибке, обрыве или превышении времени ожидания помощник переключается на `https://registry.npmmirror.com/`.
3. Если все доступные источники недоступны, обновление останавливается с сетевой ошибкой. Подготовка выполняется до замены приложения и остановки сервисов.

На попытку отведено до 120 секунд. Загрузки ограничены четырьмя параллельными соединениями; внутреннее ожидание запроса — 30 секунд с одной повторной попыткой. Выбор источника и результат записываются в журнал установки/обновления.

Используется `npm ci`: версии и контрольные суммы берутся из `package-lock.json`. Проверка TLS остаётся включённой. Lock-файл и глобальная конфигурация npm не меняются. npm подменяет только стандартный хост `registry.npmjs.org` для текущей команды. Встроенные в архив зависимости проверяются контрольной суммой родительского архива.

Ошибки целостности, сертификатов, авторизации, несовместимости пакетов, прав или свободного места не вызывают смену источника. Заданный пользователем нестандартный registry и lock-файлы с нестандартными источниками не перенаправляются на публичное зеркало.

Этот механизм относится к зависимостям интерфейса npm. Источники APT, Python, Xray и WARP он не меняет.

Помощник копируется в каталог доверенных системных инструментов при установке служебного обновлятора. Для уже установленной старой версии обновлятора потребуется один успешный переход на новую версию либо отдельное обновление системных инструментов: старый помощник сам не получит новую логику до завершения обновления.

Проверка на проблемном VPS в отдельной временной папке: основной источник оборвал загрузку с `ETIMEDOUT`, затем резервный источник установил все 67 пакетов за 6 секунд. Рабочее приложение и его настройки в этой проверке не менялись. Для ускорения диагностического сценария внешний лимит первой попытки был уменьшен до 10 секунд; штатный лимит — 120 секунд.

[Настройка registry и замены хоста в npm](https://docs.npmjs.com/cli/v11/using-npm/config/).
