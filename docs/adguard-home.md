# Пробное подключение AdGuard Home

Интеграция необязательна и по умолчанию выключена. Сейчас DNS AdGuard передаётся в Happ для клиентов с включённым персональным AdBlock. AmneziaWG и другие приложения сохраняют существующую фильтрацию Xray; их DNS автоматически не перенастраивается.

## Схема

AdGuard Home слушает только 127.0.0.1:3001 (HTTP/DoH) и 127.0.0.1:5354 (DNS). Его интерфейс управления не публикуется. HTTPS обслуживает существующая панель. Новый обработчик /api/v1/sub/{token}/dns-query проверяет действующую подписку, ограничивает размер и частоту запросов, передаёт DNS в локальный AdGuard с идентификатором клиента.

В настройках базы сервера интеграция включается ключами adguard.enabled=true и adguard.bootstrap_ip=публичный_IP_панели. PANEL_PUBLIC_URL должен содержать HTTPS-адрес панели. Сначала нужно установить и проверить локальную службу AdGuard: включать интеграцию без работающего сервиса нельзя.

Если персональный AdBlock выключен, новая подписка содержит прежние DNS-настройки. Запросы из старого профиля временно направляются в обычный Cloudflare DoH без фильтра. После переключения нужно обновить подписку и переподключить VPN в Happ.

## Пробная конфигурация

Проверено с AdGuard Home v0.107.79 и официальным AdGuard DNS filter. Служба запускается отдельным системным пользователем, без прав root. Системный DNS, DHCP и публичный порт 53 не меняются. Администратор может открыть интерфейс через SSH-туннель к 127.0.0.1:3001.

Журнал AdGuard хранит запрашиваемые домены: в пробной конфигурации срок хранения составляет сутки. Конфигурация и данные сервиса требуют отдельного резервного копирования; копия панели их не включает.

DNS-фильтр не различает рекламу и полезный контент на одном домене и не скрывает пустые рекламные места. Браузер или приложение, использующее собственный DNS, может обходить этот слой.
