# Проверка перед публичной публикацией

Дата проверки: 7 октября 2026 года. Область: исходники панели, установщики, конфигурационные шаблоны и доступная история Git. Проверка не является гарантией отсутствия всех уязвимостей.

## Выполнение команд и входные данные

`backend/app/services/shell.py` вызывает `asyncio.create_subprocess_exec` со списком аргументов. Оболочка не запускается; метасимволы в аргументе не становятся командами. Добавлен регрессионный тест передачи таких аргументов буквально.

Домены, IP и CIDR правил маршрутизации проверяются до сохранения. Имена geosite/geoip допускают только синтаксис категории и атрибута, без путей и команд. Адрес и порт регистрации ноды проверяются схемой API. URL панели и токен при формировании скрипта подключения экранируются через `shlex.quote`.

Установщик проверяет домены и email до подстановки в конфигурации. Установщик Xray скачивается из официального XTLS/Xray-install по фиксированному коммиту с проверкой SHA-256; ошибка скачивания или проверки прерывает шаг. Получение публичного IP ноды использует HTTPS.

## Оставшийся риск: backend запускается от root

Текущий systemd-юнит **запускает backend от root**. Уязвимость выполнения кода в приложении может привести к компрометации всей ОС. `UMask=0077`, авторизация API и отсутствие shell-интерполяции уменьшают отдельные риски, но не устраняют этот архитектурный риск.

Переход на отдельного пользователя отложен. Для него нужен отдельный привилегированный помощник с фиксированными операциями и проверкой параметров, а также разделение владельцев конфигураций и секретов. Разрешение `sudo python3 *`, `sudo bash *` или произвольных команд systemctl не заменяет такую изоляцию. До её реализации используйте выделенный сервер и ограничивайте доступ к административной панели.

## Секреты и история

CI запускает Gitleaks по всей доступной истории (`--all`, полный checkout) и проверяет список отслеживаемых файлов. Реальные `.env`, базы, ключи и копии не должны попадать в Git; `.env.example` содержит пустые значения или явные шаблоны секретов.

Перед публикацией из локального клона выполните:

```bash
gitleaks git --log-opts=--all --redact .
gitleaks dir --redact .
python3 scripts/check-public-files.py
git log --all --format='%ae' | sort -u
```

Сканер не проверяет автоматически файлы вложений, приватные резервные копии, сообщения вне Git, настройки GitHub и недоступные refs. Если секрет когда-либо был опубликован, его нужно отозвать независимо от очистки истории. Не прикладывайте неотредактированные логи или дампы к Issues.

## Источники загрузок

| Компонент | Источник |
| --- | --- |
| MD-Next | Текущий репозиторий `tro9n4ik/md-next` |
| Xray | Официальные `XTLS/Xray-install` и `XTLS/Xray-core` |
| AmneziaWG | Репозитории `amnezia-vpn`, PPA разработчиков; Go загружается с `go.dev` с проверкой SHA-256 |
| Node.js | Официальный установщик NodeSource и его APT-репозиторий |
| Python / JavaScript | PyPI и npm; зависимости и lock-файл находятся в репозитории |
| WARP | Репозиторий пакетов Cloudflare |
| Krawl, необязательный компонент | Upstream `BlessedRebuS/Krawl`, фиксированный коммит в установщике |
| GeoIP / Geosite | Релизы `v2fly/geoip` и `v2fly/domain-list-community` |

Стандартные DNS-адреса, приватные подсети, loopback и адреса диагностических сервисов не являются адресами сервера разработчика. Сетевые проверки используют внешние сервисы и сообщают им IP сервера. Сторонние источники и их доступность остаются внешней зависимостью; обновление закреплённых установщиков требует повторной проверки контрольных сумм.

## Воспроизводимая проверка

В CI проверяются pytest на Python 3.10–3.13, чистая сборка frontend, lint, синтаксис Bash, pip-audit и npm audit. Отдельный workflow установки/удаления запускается вручную на чистых Ubuntu 22.04, Ubuntu 24.04 и Debian 12 (amd64). Эти проверки не подтверждают работу каждого VPN-клиента, мобильного устройства или сети с ограничениями.
