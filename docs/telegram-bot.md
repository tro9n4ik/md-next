# Telegram-бот MD-Next

Бот использует одно текстовое меню. Кнопки меняют его содержимое, а обработанные команды и введённые значения убираются из личного чата. Администратор и клиент получают разные экраны. Старые команды остаются совместимыми; запоминать их не требуется.

## Администратор

Администратор определяется числовым Telegram ID в настройках панели. Служебные действия доступны только ему и только в личном диалоге с ботом.

На главном экране доступны:

- **Новая подписка.** Введите имя и проверьте итоговую карточку. По умолчанию предлагаются месяц и трафик без ограничений. Перед подтверждением можно изменить срок, общий лимит, телефон и почту. Готовые шаблоны доступны на первом шаге. До подтверждения клиент не создаётся.
- **Подписки.** Один список с поиском по имени, телефону и почте; фильтры по сроку, лимиту и паузе. В карточке показаны срок и оба месячных счётчика. Частые действия: выдать подключение, продлить, изменить условия и доступ к профилям. Персональная ссылка открывает страницу с импортом и QR-кодом.
- **Управление панелью.** Разделы клиентов и групп, нод, протоколов, DNS, маршрутизации, WARP, обхода БС, настроек, субадминистраторов, резервных копий, обслуживания, переезда и безопасности. Полное управление доступно только владельцу по Telegram ID из настроек, в личном диалоге. Субадминистраторы доступа к этим разделам не получают.
- **Система.** Состояние, выбор ноды, диагностика и события. Смена выхода требует отдельного подтверждения; старая команда `/failover` также открывает выбор вместо немедленного переключения.
- **Помощь.** Короткая инструкция по основным действиям и возврату в меню.

В «Сроке и лимитах» можно изменить общий месячный трафик, отдельный трафик обхода БС, дату окончания, имя и контакты. Ноль означает отсутствие ограничения трафика. Для удаления телефона или почты отправьте дефис. Перед применением бот показывает изменение и просит подтверждение; при ошибке ввода можно сразу отправить исправленное значение.

В «Дополнительно» находятся файл AmneziaWG, одноразовый код привязки клиента, отзыв привязки и сброс расхода. Опасные изменения подтверждаются. Подтверждение привязано к пользователю, чату и экрану, действует ограниченное время и не выполняется повторно при двойном нажатии.

### Управление из Telegram

Раздел «Ноды» сразу показывает компактный список по три ноды на экран. У каждой — флаг, название и короткий статус; под названием находятся кнопки выбора выхода, паузы/включения и удаления. IP, ID, служебные поля и отдельные подробные карточки в списке не показываются. После действия открывается тот же список. Добавление и настройки доступны внизу. Удаление, смена общего выхода и пауза активной ноды требуют одного подтверждения; включение и пауза резервной ноды выполняются сразу. Поле «Хостер» принимает название или ссылку.

Бот обращается к тем же API внутри приложения, которые использует веб-панель. Проверки полей, прав и доступности протоколов, синхронизация конфигураций и откаты остаются общими. Токен доступа создаётся только в памяти для внутреннего запроса и не отправляется в Telegram.

| Раздел | Возможности |
| --- | --- |
| Клиенты и группы | Группы, индивидуальный выход, страны в подписке, профили, блокировка рекламы, перевыпуск ссылок и ключей, удаление клиентов, шаблоны подписок |
| Ноды | Добавление по приглашению, команда установки, доступ, ссылка на хостера, резервирование, выбор выхода, автопереключение, история и команды агенту |
| Сеть | Протоколы, адреса подключения, DNS, правила маршрутизации, обход БС |
| WARP | Состояние, подготовка и проверка WARP на активной ноде, IPv4, правила, канал к нодам, мониторинг Gemini |
| Настройки | Название подписок, Telegram и уведомления, загрузка своей HTML-заглушки, генерация и восстановление заглушки |
| Субадминистраторы | Создание, доступ, права и пароль; административный бот остаётся только у владельца |
| Копии | Создание зашифрованной копии, скачивание, предварительная проверка и восстановление |
| Обслуживание | Ресурсы VPS, сервисы, диагностика, журнал, версии компонентов, проверка и установка обновления |
| Переезд | Готовность исходного сервера, отпечаток SSH, комплект переезда, этапы и состояние переноса |
| Безопасность | Пароль панели, подготовка, подтверждение и отключение 2FA |

В формах показываются текущие значения. Ноды, клиенты, группы и файлы выбираются из списков. Страны отмечаются галочками, порядок нод меняется стрелками, шаблоны редактируются по полям. Для включения профиля достаточно одного нажатия; недоступные в панели профили нельзя включить через бота.

При создании подписки кнопка «Профили» позволяет заранее выбрать доступные подключения. Выбор применяется в одной транзакции с созданием клиента до первой синхронизации сервисов. Кнопка «Создать подписку» выполняет создание сразу, без дополнительного вопроса. Для уже созданного клиента переключатели профилей сохраняются сразу.

Обычные формы применяются кнопками «Создать», «Сохранить» или «Выполнить». Дополнительное подтверждение остаётся для удаления, перевыпуска ключей и ссылок, восстановления, обновления, переезда и изменений, затрагивающих общий маршрут, протоколы или связь с ботом. Если настройки изменились в другом интерфейсе во время заполнения, старая форма не перезаписывает их: бот предложит открыть её заново.

Пароли, ключи, код проверки копии и содержимое загруженного файла скрыты в карточках. Форма и её значения удаляются из памяти по истечении 10 минут бездействия; команда `/menu` или отмена прекращает ввод. Telegram может отказать в удалении сообщения, поэтому введённые секреты нельзя считать исчезнувшими из истории устройства. Ключ настройки 2FA и команда установки ноды показываются только по отдельной кнопке владельца.

При восстановлении сначала загрузите копию и введите её пароль: бот покажет состав изменений. Затем нажмите «Перейти к восстановлению» и подтвердите замену данных. Вводить или копировать внутренний код проверки вручную не требуется.

Файлы в этом интерфейсе ограничены 20 МБ, HTML-заглушка — 1 МБ в UTF-8. Более крупные комплекты переезда скачиваются через панель. Перед переходом на другой экран сохраните выданный файл: временные вложения удаляются при навигации. Для генерации команды установки должен быть задан правильный `PANEL_PUBLIC_URL`.

Смена настроек Telegram и восстановление выполняются вне обработчика polling, чтобы бот мог перезапустить своё подключение. Если меняется токен или ID владельца, продолжите работу с новым ботом или новым аккаунтом. Во время форм и выполнения операций уведомления остаются в очереди.

## Клиент

Первый экран предлагает привязать подписку. Получите код у администратора, нажмите «Привязать подписку» и отправьте код обычным сообщением. Код одноразовый и действует 15 минут; число попыток ограничено. Пароль сервера, токен бота и личную ссылку вместо кода вводить не нужно.

После привязки клиент видит только свою подписку:

- состояние и срок;
- общий месячный расход и лимит;
- отдельный расход и лимит обхода БС;
- дату начала следующего расчётного периода;
- подключение, инструкции для Happ, v2rayNG и AmneziaWG, обновление данных.

При истечении срока, паузе или исчерпании общего лимита бот объясняет ограничение. Подменить ID клиента в кнопке для получения чужих ключей нельзя: принадлежность подписки проверяется заново при выдаче доступа. Клиентские сообщения не выполняют административные команды.

## Чистый чат и уведомления

События обновляют рабочий экран, а не добавляют отдельные карточки. В «Система → События» доступны последние темы уведомлений; повторные сообщения по одной теме объединяются. Во время создания подписки, ввода значения, подтверждения или диагностики доставка ожидает, сохраняя очередь. Настроенные типы уведомлений продолжают учитываться.

Редактирование существующего сообщения не создаёт новый звук Telegram. Для звуковых оповещений нужен отдельный режим доставки; эта версия использует единое меню.

Файлы AmneziaWG и отчёт диагностики отправляются отдельно только по явному запросу. Сохраните файл перед следующим переходом: бот убирает временное вложение при открытии другого экрана. Ссылка и QR-код доступны на личной странице подключения.

`/start` и `/menu` создают видимое меню заново, даже если Telegram продолжает принимать редактирование карточки из удалённой переписки. Предыдущая известная карточка удаляется после успешной отправки новой. Отказ Telegram в очистке не отменяет действие и не ломает меню. Историю чата бот не сканирует; сообщения старше 48 часов Telegram обычно удалить не разрешает. [Ограничения Telegram Bot API](https://core.telegram.org/bots/api#deletemessage).

## Применение обновления

Все разделы владельца используют короткие экраны: основные значения и действия рядом с объектом. В списках отображаются по три записи; дополнительные настройки доступны через «Ещё». После изменения бот возвращает обновлённый список вместо отдельного отчёта. Технические поля и JSON не выводятся; подтверждение сохраняется для опасных действий. Название хостера можно указать обычным текстом или ссылкой.

Обновите панель через веб-интерфейс, затем откройте бот командой `/menu`. Маршрут к Telegram через активную ноду сохраняется. При недоступности Telegram очередь событий остаётся в базе и повторяет доставку после восстановления связи.
