# Защищённое подключение нод

Новые подключения используют VLESS TCP + Reality с Vision. Приватный ключ создаётся на ноде и не передаётся панели. Панель получает публичный ключ и UUID по HTTPS с одноразовым приглашением. Для отпечатка используется Firefox, цель Reality — www.cloudflare.com:443.

Уже подключённые Trojan/gRPC-ноды сохраняют прежний маршрут до отдельной миграции. Их канал не становится защищённым только от обновления панели.

## Миграция существующей ноды

1. Сохранить конфигурацию Xray ноды и настройки её маршрута в панели.
2. Добавить защищённый вход на отдельном порту, сохранив старый вход.
3. Проверить выход через новый вход с сервера панели, включая DNS, WARP и доступ Telegram.
4. Только после успешной проверки переключить данные ноды в панели; проверить клиентов Xray и AWG.
5. Удалить старый незашифрованный вход после подтверждения результата. При сбое восстановить прежние настройки.

Не запускайте скрипт подключения поверх действующей ноды для миграции: обычная регистрация меняет её конфигурацию и реквизиты. Нужен контролируемый переход с двумя входами.

## Подписи обновлений

Самообновление требует успешных CI и сканирования секретов, а также verification.verified=true от GitHub. Отдельный установщик повторно проверяет подпись заданного SHA до скачивания и выполнения кода. Отсутствие подписи или недоступность проверки блокирует обновление до изменения рабочей панели.

Это проверка подписи GitHub, а не закрепление личного ключа автора. Защита main и обязательное ревью остаются необходимыми. Для выпуска используйте подписанный коммит или подписанный GitHub merge, убедившись, что GitHub показывает Verified.
