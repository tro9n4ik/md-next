# Хостер ноды и диагностика обновления

В центральном окне «Добавить ноду» появилось необязательное поле «Ссылка на хостера»: адрес личного кабинета или страницы VPS. Ссылка сохраняется в приглашении, затем переносится в ноду. Уже подключённой ноде её можно добавить, изменить или убрать в списке узлов. Это изменение метаданных не перестраивает VPN и не перезапускает службы.

Разрешены только ссылки HTTP/HTTPS без встроенного логина и пароля, длиной до 2048 символов. Панель не загружает страницу хостера сама. Ссылку видит только администратор: она не выдаётся субадминистратору, установщику ноды или клиенту подписки. При повторной регистрации той же ноды пустое поле приглашения сохраняет прежнюю ссылку; убрать её можно отдельно через редактирование.

## Ошибки обновления

На странице обновления показываются причина, этап и рекомендуемое действие. Поддержаны нехватка места, подтверждённая нехватка RAM, тайм-аут, сетевые ошибки, сбои зависимостей, сборки, резервной копии, миграции и запуска панели.

«Обновление не удалось: недостаточно оперативной памяти» отображается при подтверждённом OOM-kill в журнале службы **соответствующей попытки**. Сам по себе SIGKILL или текст `Killed` не доказывает нехватку памяти. Если подтверждения нет, показывается ошибка этапа либо неопределённая причина. Отсутствие доступа к journal не подменяется догадкой об OOM.

Если воркер был завершён до записи результата, статус уточняется по состоянию службы. Ошибка диагностики не препятствует автоматическому откату. Причина сбоя сохраняется отдельно от результата отката: можно увидеть, почему установка упала и восстановилась ли предыдущая версия.

В API возвращаются только заранее подготовленные сообщения. Содержимое `update.log`, токены, URL загрузок и параметры команд пользователю не передаются. Исходный журнал остаётся на сервере для администратора.

Для старой уже записанной ошибки этап может быть определён по хвосту журнала сборки, а OOM — по временному интервалу старой попытки. Если журналы уже удалены, точную причину восстановить нельзя. Для полной диагностики новых попыток требуется версия обновляющего помощника с этим механизмом; первый переход со старой версии может содержать меньше сведений.
