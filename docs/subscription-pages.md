# Личные страницы подписок

Существующая ссылка `/sub/<токен>` открывает личную страницу при запросе браузера с `Accept: text/html`. Для клиентов с обычным запросом сохраняется прежняя base64-подписка и её заголовки. Параметр `?format=raw` принудительно выбирает текстовый формат даже в браузере; `?format=page` открывает страницу явно.

Страница использует текущие имя, состояние, срок, расход и лимит клиента. Она не раскрывает контактные данные или ключи профилей. QR-код строится локально, без внешнего сервиса. Ссылка содержит секретный токен: не публикуйте её. При перевыпуске токена старая страница становится недоступной. Ответ запрещает кеширование и индексирование.

Подключение разбито на три шага: установить приложение, добавить подписку, выбрать профиль. Страница определяет устройство и предлагает Happ; на Android можно выбрать v2rayNG. Кнопки импорта, ссылка для ручного добавления и QR-код используют существующую подписку. QR-коды открываются по запросу, копирование сопровождается подтверждением. Если браузер запретил буфер обмена, поле выделяется для ручного копирования.

Карточка подписки показывает владельца, состояние, срок по UTC, расход и остаток общего трафика, отдельный лимит обхода БС и дату следующего периода. Безлимитные и бессрочные подписки подписаны явно. Список доступных профилей содержит короткое описание каждого; в инструкции рекомендуется только реально разрешённый профиль. На телефоне подключение расположено перед условиями подписки. Оформление поддерживает светлую и тёмную темы без внешних шрифтов и изображений.

Telegram MTProto выдаётся в отдельной карточке со ссылкой и собственным QR-кодом. AmneziaWG остаётся отдельным файлом, выдаваемым администратором. Глобальное включение протокола и персональные права применяются одновременно. Отключённые, просроченные и исчерпавшие месячный трафик клиенты видят причину ограничения и дальнейшие действия вместо кнопок подключения. Исчерпание отдельного лимита обхода БС не скрывает остальные разрешённые профили.

Раздел «Полезно знать» объясняет подключение другого собственного устройства, обновление и продление подписки, маршрутизацию Happ, ограничения обхода БС и обращение с личной ссылкой. Перевыпуск URL прекращает выдачу по старой ссылке, но сам по себе не отзывает уже скачанные ключи: для этого требуется перевыпуск профилей.

## Управление доступом

В разделе клиента выберите разрешённые профили и сохраните доступ. CDN независим от обычного XHTTP TLS, хотя использует тот же UUID: серверные входы имеют разные списки разрешённых клиентов. Старые клиенты без явной настройки CDN наследуют доступ от TLS, что сохраняет прежнее поведение при обновлении. Изменение прав не перевыпускает UUID, ключи, срок или токен подписки.

При неудачной синхронизации Xray/AmneziaWG транзакция откатывается, затем восстанавливаются конфигурации из сохранённых данных. Глобальное включение/отключение CDN также применяет серверный список доступа.

## Справка и навигация

В боковом меню панели доступна Wiki с поиском по всем разделам. На компьютере кнопка над логотипом сворачивает меню; названия остаются в подсказках и доступных именах ссылок. Выбор сохраняется только в текущем браузере. Мобильное меню сохраняет полные названия.
