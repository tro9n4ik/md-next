## Возможности

| Задача | Что есть в панели |
| --- | --- |
| Выдать доступ | Подписка, QR-коды, личная страница и отдельные подключения |
| Управлять клиентами | Группы, онлайн-статус, сроки, продление и месячные лимиты |
| Выбрать страну | Общий или персональный маршрут, дополнительные страны в подписке |
| Управлять сетью | Узлы, резервирование, DNS, правила маршрутизации и WARP |
| Работать через Telegram | Создание и продление подписок, кабинет клиента и уведомления |
| Следить за сервером | Нагрузка, трафик, события, история доступности и диагностика |
| Администрировать | Права сотрудников, двухфакторная аутентификация и резервные копии |

**Подключения:** VLESS Reality, VLESS XHTTP, Hysteria 2, AmneziaWG, Telegram MTProto и «Обход БС».
AmneziaWG выдаётся отдельным файлом, Telegram — отдельной ссылкой. Совместимость зависит от VPN-приложения и его версии.

## Установка

Проверены **Ubuntu 22.04 / 24.04 и Debian 12, amd64**. Рекомендуется чистый VPS: **1 CPU, 2 ГБ RAM, 10 ГБ диска**.
Нужны права администратора, основной домен и поддомен панели с A-записями на сервер. Домены должны быть доступны для выпуска TLS-сертификатов.

```bash
curl -fsSL https://raw.githubusercontent.com/tro9n4ik/md-next/main/scripts/bootstrap.sh | sudo bash
```

В меню выберите установку. Скрипт запросит домены и почту для Let's Encrypt, настроит службы и покажет пароль администратора. Сохраните его и включите 2FA.

<details>
<summary>Установка из клонированного репозитория и совместимость</summary>

```bash
git clone https://github.com/tro9n4ik/md-next.git
cd md-next
sudo bash scripts/install.sh
```

Репозиторий публичный, авторизация GitHub для скачивания не нужна. Установщик выполняется с правами администратора: исходный скрипт можно скачать и просмотреть перед запуском. Для воспроизводимой установки закрепите проверенный коммит.

Для arm64 предусмотрены загрузки upstream, но полный цикл установки пока не проверен. Alpine не поддерживается: используются APT и systemd. Требования к ресурсам и трафику зависят от числа клиентов.

</details>

## Обновление

Откройте **Настройки → Обслуживание → Обновление панели**. Панель проверит сборку из `main`, создаст резервную копию и выполнит обновление. При ошибке применения предусмотрен автоматический откат.

## Безопасность и границы проверки

Новые установки запускают backend от пользователя `md-next`; системные действия выполняет отдельный помощник с фиксированным набором команд. Используйте уникальный пароль, 2FA и храните внешнюю копию данных. Архивы резервных копий содержат секреты и приватные ключи.

Автоматические проверки не гарантируют работу всех протоколов во всех приложениях и сетях. [Состояние проверок](docs/release-readiness.md) · [Отчёт аудита](docs/public-security-audit.md) · [Сообщить об уязвимости](SECURITY.md).
